# ux_reference/ — referências públicas (marcadas `unverified`)

Esta pasta existe para o que se vê **fora** do binário: páginas públicas da loja,
centro de ajuda, vídeos de imprensa, capturas de terceiros.

**Estado atual: vazia por opção.** A referência deste projeto é o binário original
(`ANDOIRD/DRIVER/source-original.apk`) e as capturas `live` em
[`../ANDOIRD/DRIVER/ux_capture/`](../ANDOIRD/DRIVER/ux_capture/). Não foi necessário
usar material público para nenhum ecrã da Driver.

Regras se entrarem referências públicas:

1. Cada ficheiro leva `evidence: unverified` no nome ou numa ficha ao lado.
2. Nunca se mistura com `live`/`static` na mesma tabela sem etiqueta.
3. Não se copiam assets, marca ou copy de terceiros para o entregável; servem só para
   confirmar forma ou comportamento.
4. Uma referência pública não promove um ecrã a `live`; no máximo, a `unverified`.
